# Eco-Health Data Hub 🌍🔬

## Project Overview
This repository tracks the intersection of environmental shifts and public health metrics in Pakistan and broader South Asia. It utilizes automated data pipelines to extract, clean, and visualize localized air quality (PM2.5) and temperature anomalies to highlight risks to community health, vector-borne disease expansion, and clinical laboratory infrastructure.

## Tech Stack
- **Languages:** Python
- **Data Manipulation:** Pandas, NumPy
- **Automation & Deployment:** GitHub Actions, GitHub Pages

## How It Works
1. A Python script fetches daily environmental data from open-source APIs (OpenAQ).
2. The data is cleaned and aggregated using Pandas DataFrames.
3. The output is pushed to a live, static dashboard hosted on GitHub Pages.
